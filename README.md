# Neo BPMS

**Business Process Management System built on Neo Framework**

🔒 **Private Repository** - This is proprietary software.

## Overview

Neo BPMS is a comprehensive Business Process Management System that provides:

- ✅ **BPMN 2.0** - Full BPMN modeling support
- ✅ **Workflow Engine** - Execute complex business processes
- ✅ **Form Builder** - Dynamic form generation
- ✅ **Process Designer** - Visual process modeling
- ✅ **Task Management** - Human task assignment and tracking
- ✅ **Integration** - REST API and webhooks

## Architecture

Built on top of Neo Framework with additional layers:

```
Neo.Bpms.UI.MVC         → MVC UI
Neo.Bpms.Application    → Business Logic
Neo.Bpms.Domain         → Domain Models
Neo.Bpms.Domain.Modeling → BPMN Modeling
Neo.Bpms.Infrastructure → Data Access
Neo.Bpms.UI.Resources   → Shared Resources
```

## Technology Stack

- .NET 8.0
- Neo Framework
- ASP.NET Core MVC
- Tailwind CSS
- BPMN.js
