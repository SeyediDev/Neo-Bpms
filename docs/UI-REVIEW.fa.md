# بررسی اولیهٔ فرانت Neo.Bpms

## یافته‌ها و دامنه

فرانت MVC هم‌زمان از bundleهای قدیمی، CSS راست‌به‌چپ/چپ‌به‌راست، Tailwind، ux-theme و
فایل‌های neo-login/dashboard/detail/index استفاده می‌کند. سه پروژهٔ TypeScript جداگانه
نیز وجود دارند؛ بنابراین اصلاح یک CSS سراسری معادل یکپارچه‌سازی همهٔ فرانت‌ها نیست.

CommonIncludes.cshtml ترتیب بارگذاری را تعیین می‌کند. MyWorkItems.cshtml به شناسه‌های
فرم، SelectionManager و FilterManager متکی است و یک بلوک استایل برای کوچک‌کردن
کنترل‌های فیلتر دارد. نوار عنوان مشترک TopBar دو استایل inline برای فاصله‌گذاری داشت.

## تغییر انجام‌شده

- CSS اولیهٔ سراسری به کلاس neo-ux-toolbar محدود شد؛ رنگ body، اندازهٔ همهٔ inputها،
  حرکت hover و تغییر همهٔ انیمیشن‌ها از آن حذف شد تا دامنهٔ اثر قابل کنترل باشد.
- نوار عنوان، گوشه و سایهٔ ملایم و فوکوس قابل مشاهدهٔ کیبورد دارد.
- دو استایل inline به کلاس منتقل شد؛ margin-inline-start فاصلهٔ عنوان و آیکون را
  برای هر دو جهت متن تعریف می‌کند.
- CSS به wwwroot/css منتقل شد تا در بستهٔ Razor به‌عنوان static asset منتشر شود.
  مسیر لینک _content/Neo.Bpms.UI.MVC/css/neo-ux-polish.css است.
- JavaScript، نام ورودی‌ها، شناسه‌ها، handlerها و مسیر ارسال فرم تغییر نکردند.

## بررسی

Build هدفمند MVC/Razor بدون خطا و هشدار موفق شد. manifest انتشار CSS بررسی شد.
نمونهٔ نمایشی با markup مشابه نوار عنوان و CSS واقعی تغییرکرده، در مرورگر برای
RTL/LTR، روشن/تیره و عرض موبایل ۳۹۰ پیکسل بررسی شد. رنگ متن و اندازهٔ کنترل‌ها ثابت
ماند؛ سرریز افقی دیده نشد و فوکوس کیبورد نمایان بود.

برای بازتولید نمونه:

```powershell
python -B tools/Neo.Bpms.Companion/preview_ui.py
```

سپس http://127.0.0.1:8876 را باز کن. سرور فقط صفحهٔ نمونه و CSS را ارائه می‌کند.
این نمونه جای تست سامانهٔ واقعی با همهٔ bundleها، مجوزها، gridها و popupها نیست؛
پوشش کامل UI/UX و ریسک صفر ادعا نمی‌شود.

## مسیر ادامه

ابتدا صفحه‌های واقعی کارتابل، فرم پویا و گزارش را در محیط تست احراز هویت‌شده ثبت و
مقایسه کن. سپس با همان نمونه‌ها، توکن‌های رنگ/فاصله و کامپوننت‌ها را به‌تدریج
یکپارچه کن. ساده‌سازی JavaScript نیازمند تست رفتاریِ فیلتر، انتخاب ردیف و ارسال فرم
است؛ فعلاً با حذف و جابه‌جایی منطق، ریسک ایجاد نشده است.

بازگشت این مرحله: کلاس‌های neo-ux-* در TopBar و لینک CSS را در یک تغییر معکوس حذف
و فاصله‌های قبلی را بازگردان. بازگرداندن کل ریپو لازم نیست.
